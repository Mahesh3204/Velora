# Vibe Liquid Light

VIBE Vodka — Premium Interactive Website Design & Development Prompt

1. PROJECT OBJECTIVE

Create a completely redesigned, premium, modern, highly immersive website for VIBE Vodka.

Reference websites:

Official website: https://vibe.vodka/

Additional website: https://vibevodka.net/

YouTube reference: https://youtu.be/ACkQCyfJ480

Instagram reference: https://www.instagram.com/vibe_vodka/

Use these references primarily to understand the VIBE brand, actual products, bottle designs, logo, packaging, visual identity, product information, and photography.

Do NOT simply reproduce the existing website.

The goal is to create a new-generation luxury beverage website that feels like a combination of:

Premium vodka brand

Luxury fashion website

High-end technology product launch

Cinematic product commercial

Interactive 3D experience

Modern editorial magazine

Premium smartphone product presentation

The website should feel expensive, artistic, sophisticated, energetic, memorable and technologically advanced.

The experience should make the user think:

"This is not a normal alcohol website. This feels like a premium digital experience."

2. CORE CREATIVE DIRECTION

The visual concept should be:

"LIQUID VIBE"

Build the entire experience around the idea of:

VODKA × LIGHT × GLASS × LIQUID × MOVEMENT × VIBE

The design should visually communicate:

Smoothness

Purity

Premium quality

Energy

Celebration

Elegance

Transparency

Modern European luxury

Nightlife without becoming a dark website

Sophistication without looking boring

Avoid the generic "black background + gold text + bottle in center" luxury alcohol website aesthetic.

Instead create a bright luxury environment.

6. AGE VERIFICATION

Because this is an alcohol website, include a polished 18+ age verification experience.

Do not make it look like a boring browser popup.

Create a full-screen premium introductory scene.

Background:

Soft pearl white

Glass/liquid reflections

Subtle moving liquid/glass animation

Centered:

"GOOD VIBES
START HERE."

"Are you 18 or older?"

"YES, ENTER"

"NO, EXIT"

Make the buttons elegant and tactile.

When the user clicks YES:

background subtly expands

liquid ripple occurs

logo transitions

page smoothly zooms into the main website

Store verification appropriately so the user doesn't repeatedly see it during the same session.

The hero should be the strongest section on the website.

The bottle should use the real VIBE Vodka product image/assets from the reference website whenever possible.

Do not replace the actual bottle with a generic AI-generated vodka bottle.

8. HERO SCROLL INTERACTION

The hero should respond directly to scroll.

Use scroll-driven animation.

As the user scrolls:

Stage 1

Bottle slowly rotates.

Stage 2

Camera moves closer.

Stage 3

Typography moves horizontally and separates.

Stage 4

Bottle begins to transform / rotate.

Stage 5

A translucent glass frame moves around the bottle.

Stage 6

The bottle transitions into the next section.

Use smooth interpolation and inertia.

The movement should feel physically believable.

9. "FOLDABLE PHONE" INSPIRED INTERACTION

This is a major requirement.

Create a signature interaction inspired by premium foldable smartphone product websites.

Do NOT copy OPPO's exact design or assets.

Instead create a VIBE-specific interaction using the same conceptual storytelling technique.

Example:

A large translucent "VIBE EXPERIENCE PANEL" is initially opened flat.

As the user scrolls:

Panel begins folding

Product appears inside

Typography attaches to different surfaces

Bottle rotates with the folding structure

Information cards emerge from the folded surfaces

Camera changes perspective

Panel opens again into the next section

Think:

scroll = physical interaction

not simply:

scroll = moving webpage

The user should feel like they are manipulating a physical luxury object.

29. PERFORMANCE

This is extremely important.

Do NOT build a visually impressive website that runs at 20 FPS.

Use:

Lazy loading

Image compression

WebP / AVIF where appropriate

Lazy-loaded videos

GPU-friendly transforms

Efficient shaders

Reduced particle counts on mobile

Reduced 3D quality on mobile

IntersectionObserver

Code splitting

Progressive loading

Target:

Smooth 60 FPS desktop experience

Smooth mobile scrolling

Fast initial page load

Use a reduced-motion accessibility mode.

If prefers-reduced-motion is enabled:

Disable intense 3D motion

Reduce parallax

Remove excessive transitions

Keep content fully accessible
